# SmartAssist AI 🤖

**An AI-powered virtual assistant for learning, coding, document understanding, and productivity.**

SmartAssist AI is a web-based Generative AI project designed to help users ask questions, understand programming concepts, study more effectively, and interact with PDF documents through an AI-powered chat interface.

## ✨ Features

- **AI Chat:** Ask questions and receive AI-generated responses.
- **Study Assistant:** Explain concepts, summarize notes, and support learning.
- **Code Assistant:** Understand code, identify potential bugs, and suggest improvements.
- **Chat with PDF:** Upload supported PDF documents and ask questions about their content.
- **Conversation History:** Keep recent conversations organized by section.
- **User Authentication:** Sign up and sign in using Supabase.
- **Settings and Personalization:** Manage available account and application preferences.
- **Responsive Interface:** Access the application through a modern web interface.

## 🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express
- Generative AI: Google Gemini API
- Authentication and backend services: Supabase
- Version Control: Git and GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Git
- A Google Gemini API key
- A Supabase project and the credentials required by the application

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/smartassist-ai.git
   ```

2. Open the project directory:

   ```bash
   cd smartassist-ai
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a local `.env` file using `.env.example` as a reference.

5. Add your own Gemini and Supabase credentials using the exact environment variable names required by the project.

6. Start the application:

   ```bash
   npm start
   ```

7. Open the local URL printed by the server, commonly `http://localhost:3000` if configured that way.

## 🔐 Environment Variables

Keep API keys, credentials, and other secrets in your local `.env` file. Never commit real secrets to GitHub.

Refer to `.env.example` for the required variable names.
